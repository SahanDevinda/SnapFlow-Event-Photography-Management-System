# SnapFlow Frontend

React + Vite + Tailwind CSS frontend for the SnapFlow Event Photography Management System.

## Setup

```bash
npm install
npm run dev
```

Runs at http://localhost:5173  
API requests to `/api/*` are proxied to http://localhost:8080

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/pages/` — Public + role-based pages
- `src/components/` — Layout, badges, spinners
- `src/services/api.js` — Axios API client
- `src/context/AuthContext.jsx` — JWT auth state
